# Kali Linux Learning Lab 🐉

## Overview
This repository documents my hands-on learning journey with Kali Linux, focusing on Linux command-line fundamentals, cybersecurity tools, and safe lab-based security exercises.

## Environment
- **Operating System:** Kali GNU/Linux Rolling
- **Version:** 2026.2
- **Architecture:** x86_64
- **Focus Areas:** Linux fundamentals, security tool exploration, network analysis, and digital forensics

## Learning Objectives
- Practise essential Linux commands and file-system navigation.
- Understand the purpose and appropriate use of Kali Linux security tools.
- Explore basic network analysis and digital forensics concepts.
- Document practical exercises with commands, observations, and screenshots.
- Develop clear technical documentation for a cybersecurity portfolio.

## Repository Structure
- `commands/` — Linux command practice and explanations.
- `tool-notes/` — Notes on Kali Linux tools I explore.
- `screenshots/` — Evidence from completed exercises, with sensitive information removed.

## Lab Safety
All practical exercises will be performed on my own system, authorized lab environments, or data I have permission to analyze.
